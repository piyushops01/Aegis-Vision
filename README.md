> AegisVision is a browser extension designed to protect users from phishing attempts, social engineering attacks, and deceptive online content in real time. Built as a Manifest V3 Chrome/Edge extension, it scans the current webpage for suspicious keywords and patterns, displays a warning modal when a potential threat is detected, and logs the event for monitoring. The project combines a lightweight front-end popup and dashboard experience with a background service worker to provide a simple yet effective first-line defense against online scams and impersonation tactics.
